# Agent Note: 主页起始状态与品牌色板锁定

Status: implemented

[English](2026-11-02-home-start-state-brand-palette.md) | 中文

## Problem

聊天外壳打开时是一个紧凑的居中主视觉区，不带任何产品标识；外壳的深色场景使用与 SecScan RedTeam 标识无关的通用网格色调（靛蓝、青色、紫色）。产品负责人锁定了一份组合好的主页样例，并要求其颜色与光影——即标志本身的颜色——为整个聊天窗口赋予品牌感，主页与聊天皆然。

## Decision

主对话实例的主视觉阶段即主页起始状态：输入区座位成为主视觉面板（96px 标志、尾字为菱形红的字标、标语、常驻输入框、收藏条），指南区段（快速开始、常用命令、继续，以及包含概览/机队/指南的侧栏面板）在滚动主体的主页网格中围绕其组合。输入区座位的父级永不改变，因此发起会话不会重新挂载编辑器。嵌入实例保留紧凑的居中主视觉区。

品牌色板在外壳样式表中令牌化（`--brand-red` `#CF2B4D`、`--brand-blue` `#38BDF8`、`--brand-ink` `#0B1120`，逐字取自 `apps/desktop/resources/icon.svg`），框架的深色背景即样例的点亮场景（左上白光池、右上红光池、左下蓝光池、右下暖光池，覆于深锌基底之上），深色玻璃填充与模糊移至样例锁定值（`0.04`/`0.055`/`0.07`、`blur(14px) saturate(140%)`），且在对话根内，发送动作与业务主色强调改用十字线蓝。同样三个十六进制值已用于 HTML 报告，因此主页、聊天与报告共用一套品牌系统。

主页上的每个命令都是真实的：composer 命令通过会话的公共输入动作执行，与手输无异（无参数命令直接提交；带参数命令插入并聚焦），runner 协议命令作为普通消息文本插入，继续列表展示真实的最近会话。收藏是 `ui-conversation` 中一个小型固定命令源，按配置文件持久化于 localStorage，默认为新会话、`/scan`、`/status`、`/report`、`/model`，并通过注入 hooks 隔间交付给工厂。

玻璃令牌表还新增了样例无法表达的两个回退块：`@supports not (backdrop-filter: …)` 下的不透明填充与强制颜色映射；`prefers-reduced-transparency` 已由既有令牌折叠覆盖。

## Alternatives considered

**独立的主页页面或门控屏。** 被产品方向否决：主页是聊天外壳的起始状态，其上的输入框会立即发起会话。

**在对话工厂注册上声明固定命令存储。** 工厂声明目前没有存储席位；注入 hooks 隔间是注册者私有响应式事实的既定通道（composer 阻断源即先例），因此固定列表经此交付，而不扩大工厂契约。

**在主题表中全局重绑信息蓝令牌。** 重绑作用域限定在对话根内：锁定针对的是聊天窗口，其他表面保留主题自身的值。

## Consequences

桌面应用在打包版与本地版中都打开品牌主页，常驻聊天表面也位于同一点亮品牌场景之上。通用主视觉标题与预览徽章仅保留在紧凑的嵌入主视觉区中。固定旧主视觉与旧背景的快照金样需随此变更刷新；该刷新属有意输出变更，记录在落地报告中。
